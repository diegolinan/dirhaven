01

Check your ChatGPT access

OpenAI plans and workspace policies determine what the connection can do.

ChatGPT Web full MCP support is documented for Business and Enterprise/Edu accounts, subject to workspace permissions. You can still use Dirhaven with other local MCP clients.

Dirhaven cannot read your ChatGPT plan or bypass your workspace's permissions. Review OpenAI's current requirements.

02

Set your boundaries

No drive names, home folders, or mount points are assumed.

Windows: C:\Users\you\Projects · macOS: /Users/you/Projects · Linux: /home/you/Projects

Broad access is powerful.

On Windows this covers accessible drive letters, not every UNC share. On Linux and macOS it covers filesystems under /. It won't elevate permissions, but an MCP client can request changes to real files.

04
Connect to ChatGPT Web
These are separate steps. Local configuration isn't proof that a tunnel or plugin is connected.

        

          
1
Create or reuse a private tunnel
Use OpenAI Platform tunnel settings. Confirm the correct Platform organization, ChatGPT workspace, and Read/Use/Manage permissions.
Open tunnel settings ↗

          
2
Configure the official tunnel client
Point its local stdio command to your Dirhaven executable and chosen access scope. Keep API keys in protected local secret storage, never in this wizard or a shared configuration.
Read official tunnel quickstart ↗

          
3
Verify connection health
Run the official tunnel-client doctor command for your profile, then keep the tunnel client running and check its readiness.

          
4
Add your own custom MCP plugin
In ChatGPT Web, open Plugins, select Add custom MCP server, choose Tunnel, and use your own tunnel ID. Approve the plugin's discovered tools.
Open ChatGPT ↗

          
5
Test a real file operation
Test a permitted folder in ChatGPT, confirm the tool runs and verify the result locally. Do not regard the connection as complete until this works.

        

        
Dirhaven never creates a shared public plugin. Each user owns their connection. Steps may change as OpenAI updates its interface; always defer to the linked official documentation.
